---

# 📖 Project Overview

MediSwift is a desktop-based online medicine delivery application developed using JavaFX and MySQL. It enables users to browse medicines, manage their shopping cart, place orders, and maintain customer information through an intuitive graphical interface.

The project demonstrates database connectivity, desktop application development, and order management using modern Java technologies.

---

# ✨ Features

- 👤 Customer Registration & Login
- 💊 Browse Medicines by Category
- 🔍 Search Medicines
- 🛒 Shopping Cart Management
- 📦 Place Medicine Orders
- 📋 Order History & Status
- 🗂️ Category Management
- 💾 MySQL Database Integration
- 🖥️ JavaFX Desktop Interface

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/Dharamraj05/mediswift.git
```

## Navigate to Project

```bash
cd mediswift
```

## Create Database

Import the provided SQL schema:

```text
mediswift_schema.sql
```

## Configure Database

Update your MySQL credentials in the database configuration file.

## Run Project

```bash
mvn javafx:run
```
